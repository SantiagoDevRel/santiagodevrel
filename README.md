## 🌍 About Me

I build AI developer tools and production software. At Arkiv, I lead developer relations and ship tools that help coding agents and developers use a new database: MCP servers, Agent Skills, telemetry, and open-source npm packages. I also built a Claude Code tool gate at ETHGlobal Lisbon.

I also build and operate full products: [Dale Ve!](https://daleve.co), a football fan app live on the web and iOS, with its Android app in Google Play closed testing; [La Polla](https://github.com/SantiagoDevRel/la-polla-app), a football prediction platform; and Agent Relay, a local system that coordinates coding agents through bounded tasks, isolated worktrees, and executable acceptance checks.

My focus is **AI coding agents, developer infrastructure, and evaluation**. My background in Web3 and developer communities across LATAM and Africa gives me real products and builders to test these tools against.

- 🏢 Currently: **Senior Developer Relations Engineer @ [Arkiv](https://arkiv.network) (Golem Network)** — the Web3 database
- 🤖 Shipped: a production **MCP server** ([live](https://arkivmcp.vercel.app)) with developer telemetry, **Agent Skills**, a **Claude Code tool gate**, and multi-agent pipelines on the Claude Agent SDK
- 📦 Open source on npm: [`arkiv-sync`](https://www.npmjs.com/package/arkiv-sync) & [`arkiv-graph`](https://www.npmjs.com/package/arkiv-graph)
- 🎤 Speaker at ETHDenver, ETHCC, ETHAccra, ETHOxford, ETHBucharest, ETHTallinn, and 10+ more
- 🎓 Master's in Blockchain Technologies — **UPC Barcelona**
- 🌐 Languages: **English** | **Spanish** | Portuguese (working)

## 🤖 AI developer tools and evaluations

- 🔌 **Arkiv MCP** — local and remote transports, authentication, and a privacy-minimized dashboard for tool calls, errors, and usage patterns → [live server](https://arkivmcp.vercel.app)
- 📜 **Agent Skills and Claude Code plugin** — reusable build instructions and a tool-call gate that can stop a flagged MCP action for human review → [SureX source](https://github.com/SantiagoDevRel/surex)
- 🧪 **Model evaluation for MCP security** — built 17 executable MCP fixtures with ground truth written before model runs, then combined model reviews with a deterministic capability scan. Calibration is on these purpose-built fixtures, not an external benchmark → [SureX](https://github.com/SantiagoDevRel/surex)
- 🧭 **Agent Relay** — built a local coordination system for Claude Code and Codex: explicit task dependencies, isolated Git worktrees, file ownership, and acceptance checks before integration. Private local tool; architecture and demo available on request.
- 🤝 **Multi-agent pipelines** on the Claude Agent SDK — curated 124 hackathon submissions into a [104-project ecosystem dataset](https://arkiv-hub.vercel.app/ecosystem); competitive-intel [research agent](https://github.com/SantiagoDevRel/devrel-research-agent)
- 🧩 **Builder feedback as engineering evidence** — checked 286 Arkiv findings from 14 hackathon teams against source, code, on-chain data, and MCP telemetry; organized them into product asks for engineering
- 📖 **LLM-readable docs** — AGENTS.md-first documentation so coding agents integrate SDKs without breaking invariants
- 🖥️ **Local AI lab** on NVIDIA DGX Spark — self-hosted LLM & diffusion pipelines, remote MCP hosting through Cloudflare Tunnels
- ⚽ **ML × LLM hybrids** — [football value-bet engine](https://github.com/SantiagoDevRel/football-prediction-bot) (Dixon-Coles / Elo / XGBoost / Bayesian ensemble + LLM-generated features)
